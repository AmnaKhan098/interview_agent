# Interview Agent

An AI-powered interview preparation platform built with Next.js. Interview Agent generates job-specific interview questions, collects a candidate's answers, and produces AI-scored, constructive feedback — helping users practice and improve before the real thing.

## Overview

Users create an account, start a new interview session by describing a target job title and description, and receive a set of tailored interview questions generated by Google's Gemini model. After answering, each response is evaluated individually — returning a score and constructive feedback per question, plus an overall session summary. Past interviews, scores, and feedback are stored per user and viewable from a dashboard.

## Features

- **Authentication** — email/password registration and login with JWT-based sessions
- **AI Question Generation** — job title and description are sent to Gemini to produce tailored interview questions
- **AI Feedback Scoring** — each answer is scored out of 10 with constructive, per-question feedback
- **Interview History** — past interviews and their status (In Progress / Completed) are tracked per user
- **Feedback Review** — detailed breakdowns of past feedback, with an all-feedbacks view
- **Practice Modes** — dedicated behavioral, coding, and mock interview practice pages
- **Dashboard & Progress Tracking** — summary view of activity, goals, and progress
- **Community Section** — discussions, mentorship, and success stories
- **Profile Management** — user profile with title, location, bio, and avatar

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4 |
| Database | SQLite (`sqlite`, `sqlite3` / `better-sqlite3`) |
| Authentication | JWT (`jsonwebtoken`), password hashing (`bcryptjs`) |

| Animation / UI | Framer Motion, GSAP, Lucide React, Heroicons, React Icons |

## Architecture

| Area | Responsibility |
|---|---|
| `src/app/api/auth/*` | Registration, login, logout, current-user (`me`), and profile management |
| `src/app/api/interview/*`, `interviews/` | Creating interviews and retrieving interview records |
| `src/app/api/generate-questions` | Sends job title/description to Gemini and returns generated interview questions |
| `src/app/api/generate-feedback` | Sends each question/answer pair to Gemini and returns a score and feedback |
| `src/app/api/process-feedback`, `feedback/*` | Persists and retrieves feedback and per-question breakdowns |
| `src/app/api/dashboard`, `user` | Aggregated data for the dashboard and user info |
| `src/lib/db.ts` | SQLite connection singleton and schema (`users`, `interviews`, `feedbacks`, `question_feedbacks`) |
| `src/lib/auth.ts`, `utils/jwt.ts` | Authentication logic and JWT signing/verification |
| `src/lib/contexts/AuthContext.tsx` | Client-side auth state provider |
| `src/middleware.ts` | Route protection middleware |
| `src/app/*` (pages) | Dashboard, interview session, practice modes, feedback, community, profile, progress, goals, schedule |
| `src/components/` | Shared layout (Sidebar, Footer, AvatarDropdown, NotificationBell) and UI components |

## Data Model

| Table | Description |
|---|---|
| `users` | Account details — email, hashed password, name, title, location, bio, avatar |
| `interviews` | Interview sessions — job title/description, tech expertise, years of experience, status |
| `feedbacks` | Overall feedback and score for a completed interview |
| `question_feedbacks` | Per-question answer, feedback, and score, linked to a feedback record |

## Installation

**1. Clone the Repository**

| Step | Command |
|---|---|
| Clone | `git clone https://github.com/AmnaKhan098/interview_agent.git` |
| Enter directory | `cd interview_agent` |
| Install dependencies | `npm install` |

**2. Configure Environment Variables**

| Variable | Purpose |
|---|---|
| `GEMINI_API_KEY` | Google Generative AI API key used for question and feedback generation |
| JWT secret (as referenced in `src/lib/utils/jwt.ts`) | Used to sign and verify authentication tokens |

**3. Run the Development Server**

The app runs on Next.js with Turbopack and is available locally once started, by default on port 3000.

## Usage

**1. Account & Session**

| Step | Description |
|---|---|
| Register | Create an account with name, email, and password |
| Log in | Authenticate to receive a JWT-based session |

**2. Start an Interview**

| Field | Description | Required |
|---|---|---|
| Job Title | Target role for the interview | Yes |
| Job Description | Context used to generate relevant questions | Yes |
| Tech Expertise / Years of Experience | Additional context for question relevance | No |

**3. Answer & Receive Feedback**

| Step | Description |
|---|---|
| Answer questions | Respond to each AI-generated question |
| AI evaluation | Each answer is scored out of 10 with constructive feedback |
| Overall summary | An overall score and summary are generated for the full session |

**4. Review Progress**

Past interviews, scores, and detailed feedback are available from the dashboard and feedback history views.
